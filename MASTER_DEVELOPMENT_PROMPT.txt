# MASTER DEVELOPMENT PROMPT
# Project: school-mgmt-erp-service
# Product: Commercial Multi-Tenant School Management SaaS

## 1. ROLE

Act as a Principal Software Architect, Node.js Backend Engineer, MongoDB Database Architect, SaaS Security Engineer, and API Platform Developer.

Develop a production-oriented backend service for a commercial School Management ERP.

The service must support multiple educational organizations, schools, branches, academic sessions, students, staff, parents, and administrative users.

Build a reusable, metadata-driven backend architecture that will later integrate with an Angular 22 frontend.

Do not generate a demo application. Build a modular, scalable, secure, maintainable backend foundation.

# 9. DATABASE MODEL GENERATION

Create Mongoose schemas and models for all registered entities.

Each entity must have a dedicated schema.

Use:

- ObjectId references.
- Schema validation.
- Compound indexes.
- Unique constraints.
- Tenant-aware unique indexes.
- Timestamp support.
- Soft deletion.
- Schema versioning.
- Appropriate collection names.

Create index definitions separately.

Do not use a single generic schema for all entities.

Metadata describes the entity, while Mongoose schemas enforce database integrity.

Use metadata to generate safe CRUD validation, not to replace database schemas.
